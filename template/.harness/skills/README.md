# Shared skills

**These skill directories are rendered for each selected CLI, together with their supporting files.** Shared `AGENTS.md` governs workflow rules; `../README.md` governs the source format.

| Directory | Role |
|---|---|
| `add-skill/` | Admit, re-pin or remove an outside skill through its checks, and list what a tracked skill's change touches |
| `add-task/` | Add, rename, or remove a public task and its gate wiring |
| `design/` | Design a feature up to Gate 2: decision records, modules, contracts, NFRs and the test plan; includes the NFR list, the test layers and a worked example |
| `open-pr/` | Open a pull request, watch checks, and finish integration |
| `plan-stories/` | Slice an approved feature into stories, check traceability, and file them |
| `refine/` | Turn a request into a feature's confirmed use case, non-goals and acceptance criteria, up to Gate 1; includes a worked example |
| `review-feature/` | Review a feature whose stories are closed, reconcile its spec with what shipped, and close it |
| `root-cause/` | Diagnose failures before attempting a fix; includes the source license |
| `should-i-adopt/` | Assess an adoption decision and its integration costs |
| `work/` | Work an issue through claiming, implementation, validation, and integration |
